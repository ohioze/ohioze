## 👨🏽‍💻 About Me

I am a **Senior DevOps Engineer** focused on cloud infrastructure, CI/CD, Infrastructure as Code, production reliability, observability, security, and operational automation across enterprise environments.

My engineering mindset is simple: **reduce risk, remove unnecessary manual work, improve visibility, and make production systems easier to operate.**

Currently, I support business critical financial platforms at **London Stock Exchange Group**, working across AWS infrastructure, Terraform, Ansible, GitLab CI/CD, Datadog, CloudWatch, Systems Manager, Docker, Kubernetes, Linux, Windows Server, patching, release readiness, incident response, and production change controls.

## 🧭 Engineering Principles

> **Automate repeated work, but understand the failure mode before automating it.**

> **A deployment is not finished when the pipeline is green. It is finished when production is healthy.**

> **Observability should help an engineer decide what to do next, not simply generate more alerts.**

> **Good DevOps means ownership across delivery, reliability, security, operations, and recovery.**
